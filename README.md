# 農業の統計ポータル（試作版）説明書

作成日：2026年11月13日

## このサイトは何か
国（農林水産省）が公表している農業の統計を、1か所で見られるようにするサイトです。
数字ごとに、調査の時期、版（概数値・確定値など）、公表日、出典のリンクを表示します。
見せる相手は、農家さんと、会員企業（商社・メーカー）です。

## いまの状態（試作版）
- 載っている数字は、農林水産省の公式ページで確認して、手で data.json に写したものです。
- 自動更新は、まだありません。数字が変わったら、手で data.json を直します。
- 出典を確認できていない項目は、数字を載せず、「追加を予定している項目」に並べています。

## ファイルの役割
- index.html：画面です。data.json を読んで表示します。
- data.json：数字と出典の一覧です。画面に出る内容は、すべてここにあります。
- sync_embedded.py：data.json の内容を、index.html の中の控えに写します。

## 数字を直すとき
1. data.json をメモ帳などで開き、数字や日付を直す
2. 出典の URL（source_url）も、合わせて確認する
3. 保存して、同じフォルダで「python sync_embedded.py」を実行する
4. GitHub に data.json と index.html をアップロードする

index.html を、ファイルのまま直接開くと、data.json を読めないため、控えのデータが表示され、赤い注意が出ます。公開したあとのサイトでは、出ません。

## 画面の見せ方について
- 上の田畑の絵と、各分野の絵は、index.html の中に直接書いてあります（外部の画像はありません）。
- 文字の形（明朝体と丸ゴシック系）は、Google Fonts から読み込みます。読み込めないときは、お使いの機器の標準の文字で表示されます。
- 図は、data.json の chart の欄の数字から描きます。chart の数字は、出典に書かれている値を、そのまま写したものです。
  - pct：5年前との増減の割合（減は負の数）
  - parts：田と畑の面積（割合の棒に使う。num は万ha）
  - num：金額の棒の長さに使う数（億円）
- 暗い画面の設定（ダークモード）にも、対応しています。

## 数字を足すとき
data.json の items に、1件ぶんを足します。必要な項目は、title、value、change、basis（調査の基準日）、version_label（確定値など）、published（公表日）、source_name、source_url です。出典の URL がないものは、載せないでください。

## 数字の扱いの決まり
- 出典のページに書いてある数字だけを載せる。計算で出した数字や、予想は載せない。
- 同じ統計に、概数値と確定値があるときは、確定値を主に出す。以前の版は、history に残す。
- 公表日が、出典に書かれていないときは、その旨を書く（推測で日付を入れない）。

## これから作るもの（予定）
- 政府統計の総合窓口（e-Stat）の API から、数字を自動で取る仕組み
  - アプリケーションID（無料で登録）が必要です。IDは、ファイルには書かず、GitHub の Secrets に登録します。
  - どの統計表から取るかは、e-Stat の表を実際に見て決めます。
  - e-Stat の利用規約では、出典の表示が求められています。
- 確定値が出たときに、自動で差し替える仕組み
- 都道府県別の数字、基幹的農業従事者の数、価格の動き

## 公開について
- 置き場所は、補助金ポータルとは別の GitHub リポジトリにします（同じ場所に混ぜない）。
- Cloudflare Pages に、新しい公開の設定（プロジェクト）を作ります。
- 画面には、検索に出にくくする設定（noindex）を入れています。これは、見られなくする仕組みではありません。URL を知っていれば、誰でも見られます。

## 管理について
- 管理しているサービスと、登録のメールアドレスは、別の管理表に書きます（パスワードや鍵は、書かない）。
