画面の確認

    4送る

    ボタンを押すと、GitHub の画面が新しいタブで開きます。開いたら、中身は変えずに、緑の「Submit new issue」ボタンを押してください。1~2分で、サイトに反映されます。結果は、その画面にコメントで返ってきます。

    GitHub に送る

    うまく開かないとき
    1. 「内容をコピー」を押します。
    2. GitHub の、この統計サイトのリポジトリを開き、「Issues」→「New issue」を押します。
    3. 題名の欄には、コピーした内容の1行目(「[統計更新]」から始まる行)を貼ります。本文の欄には、コピーした内容の全体を貼ります。
    4. 「Submit new issue」を押します。
